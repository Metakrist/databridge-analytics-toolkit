Core capabilities:
1. Load Your Data – Import Excel and CSV files.
2. Automatic Column Detection – Identify and display the actual column names available in the uploaded dataset without assuming predefined field names.
3. Data Exploration – Understand records, columns, data types, and missing values.
4. Data Cleaning – Identify duplicates, inconsistencies, and incomplete records.
5. Data Analysis – Perform descriptive statistics and basic analysis.
6. Visualization – Create charts and graphical summaries.
7. Export Results – Save cleaned datasets and analysis outputs.
8. Learning Guide – Explain what each analysis does and how to interpret the results.
